### A line carries a marker when its first non-whitespace characters are
### exactly that marker and its run of hashes is the same length. `##:` is
### prose and `#:` is TOML text, both the tool's. `####:` and a plain `#` are
### the person's, and are kept as written.
--- DEF ---
##: Documented.
value = 1
--- USR ---
####: four hashes is not a marker
#not spaced
##:also the tool's prose, so it goes
#: value = 0
value = 2
--- RES ---
##: Documented.
#: value = 1
####: four hashes is not a marker
#not spaced
value = 2
